# 有限会社 奥田はなや — Webサイト デザインサンプル

北海道空知郡上富良野町の生花店・葬祭業「有限会社 奥田はなや」様向けのWebサイトサンプルです。

> **制作中のため、内容は確定ではありません。**
> 社名・ロゴ・住所・電話番号・役員名・会社概要は実データです。
> 一方で、**写真はAI生成の仮画像**、**火葬式と一般葬の料金は仮の数値**のままです。
> 先方のご要望により、ページ上の「デザインサンプル」告知は削除しました。
> 誤認防止のため `noindex` と `robots.txt` は引き続き設定しています。
>
> 制作確認用の機能は URL に `?check=1` を付けると有効になります。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `index.html` | 公開用。画像を `assets/` から読み込みます |
| `index-standalone.html` | 単一ファイル版。画像をbase64で内包しているので、これ1つで開けます（メール添付・オフライン確認用） |
| `assets/` | ロゴ・写真 |
| `robots.txt` | 検索エンジンへの登録を禁止 |

## デザイン方針

- 理念「**想いをつなぎ、命をむすぶ**」を軸に構成
- ベースは**クリーム**、アクセントは**薄いパステルパープル**（上富良野のラベンダー）
- 締め色はロゴから抽出した**ブランドネイビー `#012E6F`**
- 「花屋が営む葬儀社」という成り立ちを前面に出し、お別れの花とお祝いの花を対等に扱う
- 料金を先頭に置かず、総額表示・追加費用なし・書面交付という誠実さで信頼を得る導線

## 制作確認用の機能

通常表示では出ません。URL の末尾に `?check=1` を付けてアクセスすると、
写真の「AI生成イメージ」表記とページ最下部の「**確認用：差し替え箇所を表示**」ボタンが現れます。
ボタンを押すと仮データが黄色くハイライトされ、各写真枠に撮影指示が表示されます。

```
https://playmark0227-svg.github.io/okuda-hanaya-preview/?check=1
```

## 差し替えが必要な情報

- 代表取締役のお名前、専務取締役 奥田 壮様との続柄
- 設立年・創業年・資本金・施行実績
- とかちだけ倶楽部の入会金・年会費・特典の実数値
- 実際のプラン名と料金
- 対応エリアの正確な範囲
- 夜間の電話受付ルート（フリーダイヤルの有無）
- ロゴのIllustratorデータ（現状はJPGからの抽出）
- 実写写真一式
